# 什么是ComfyuGUI？
是一种类似UE的蓝图工具，用于生成UGUI的一些模板、流程化工具，一次配置一键制作。
作为技术交流为目的，采用最宽松的MIT协议，允许随意商用更改重新发布。

# Demo
## 简易的Prefab模板设置
所选对象->等于指定Prefab->拆分bool->True->获取对象列表->设置显隐藏
## 多模板Prefab设置
上方相同...True->枚举节点(Var)->获取对象列表->设置显隐
通过[Var]类节点开放编辑器可选参数，可以使用自定义的【枚举节点】去设置执行走向。
## 简易Prefab组件库
枚举节点(Var)->实例化对象
在操作面板中可检索生成库中可枚举的对象模板，置顶后可方便快速生成，也可以置顶多个或设置平铺后把枚举铺成按钮
## 嵌套分类组件库
枚举节点(Var)->枚举节点(Var)->实例化对象
通过双重嵌套的节点会根据第一层所选，获取后面的枚举内容，也可以进行平铺，平铺后默认以文件夹形式展示所有内容

# 关键特性
## - 可视模板化
简单的可视化连线操作建立模板
## -智能操作面板
根据节点情况匹配蓝图，开放操作参数面板
## -简单储存
快速保存会根据蓝图关键内容进行归纳存储，也支持自定义存储
例：所选对象会存储到{cgf}/SelectionFlow、实例化对象会存储到{cgf}/GenerateFlow
